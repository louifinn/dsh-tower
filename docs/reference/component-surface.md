# Component surface (generated)

> Generated by `npm run docs:generate:components` from `scripts/component-surface.json` and
> `scripts/surface-baseline.json`. Do not edit by hand.

Decision: [ADR 0005](../adr/0005-component-surface.md) · decision date: 2026-10-23 · baseline 2026-10-23 · visible components: 1 (`tower-bundle`)

The component axis answers one question for every config key: may a user turn it
off, and if so, must that switch be a component? Four classes cover every key, so
"should this be a component?" is a table lookup rather than a judgement call.

| Class | Meaning |
|---|---|
| `core` | Removing it breaks the Tower contract. It is never a switch. |
| `optional-component` | A capability whose off state leaves the rest of Tower intact. It must be a user-visible switch with a documented fallback. |
| `optional-config` | A tuning knob, not a capability. It stays in the config form and never hides a component. |
| `forbidden-to-disable` | The host, the health contract, the recovery escape, the review contract and the merge gates. No group, row or boolean key may turn it off. |

## Components

The shipped `cordis.patch.yml` rows, with the fallback contract each off state
must satisfy. A visible row is a component the plugin page may switch; an internal
row is a section of its parent and is not independently switchable.

| Component | Scope | Kind | Off state and fallback |
|---|---|---|---|
| `tower-bundle` | visible | group | Off equals uninstalling: no Tower tools, presets or skills remain. That is the accepted all-off boundary, not a state below it. |
| `tower` | internal | row | No Tower host: nothing works. Mandatory dependency, never a switch. |
| `tower-skills` | internal | row | The 3 skills leave the catalog; worker/reviewer PROTOCOL sections still ship through systemPrompt.section, so only the tower-recovery guidance is lost. Qualifies as an optional component (#121). |
| `preset-tower-worker` | internal | row | tower_spawn fails without the worker preset. A dependency, not a feature, never a switch. |
| `preset-tower-reviewer` | internal | row | The reviewer cannot be dispatched; with review.requireReview false merge is unaffected. Qualifies as a conditional optional component (#121). |
